# DynTP-Observ

> 分布式线程池可观测与动态管理平台

DynTP-Observ 是一个面向分布式业务系统的线程池可观测平台。项目当前已搭建基于 Spring Boot 的服务端与 Vue 3 管理端，提供统一的登录认证、权限控制和系统管理能力，为后续线程池发现、运行监控与动态调参等能力提供基础支撑。

## 平台现有功能

- 用户登录与退出：支持账号密码登录、Token 会话校验及退出登录。
- 权限与动态路由：根据当前用户拥有的角色和菜单生成管理端路由及侧边栏菜单；未登录访问管理页面会跳转至登录页。
- 用户管理：支持用户分页查询、新增、编辑、单个或批量删除，以及为用户分配角色。
- 角色管理：支持角色分页查询、新增、编辑、单个或批量删除，以及菜单权限关联。
- 菜单管理：支持以树形结构维护目录、菜单和按钮权限，并支持新增、编辑、单个或批量删除。
- 个人中心：支持查看当前账号资料，更新头像、昵称、邮箱和登录密码。
- 文件上传：支持头像等文件上传，并通过 MinIO 进行对象存储。
- 认证日志：记录登录认证相关日志；管理端支持分页查看、查看详情、单个删除和批量删除。
- 管理端界面：提供响应式后台布局、可折叠侧边栏、面包屑导航及首页概览页面。

## 技术栈

| 分类 | 技术 |
| --- | --- |
| 后端 | Java 21、Spring Boot 4、Spring Security、MyBatis-Plus |
| 前端 | Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router |
| 数据与缓存 | MySQL、Redis |
| 消息与存储 | RabbitMQ、MinIO |

## 项目结构

```text
DynTP-Observ/
├── dynTP-common/             # 公共模型、常量与通用能力
├── dynTP-framework/          # 安全、缓存、数据源、消息队列及异常处理
├── dynTP-monitor/            # 认证日志监控模块
├── dynTP-observ-service/     # 可观测业务服务预留模块
├── dynTP-starter/            # Spring Boot 启动模块与配置
├── dynTP-system-service/     # 登录、用户、角色、菜单与文件服务
├── DynTP-Observ-Web/         # Vue 3 管理端
└── pom.xml                   # Maven 父工程
```

## 管理端页面

| 页面 | 当前能力 |
| --- | --- |
| 欢迎页 | 展示平台定位、核心能力与技术栈介绍 |
| 登录页 | 账号登录与会话建立 |
| 后台首页 | 展示平台介绍与可观测能力概览 |
| 用户管理 | 用户查询、维护、角色分配与批量删除 |
| 角色管理 | 角色查询、维护、菜单权限配置与批量删除 |
| 菜单管理 | 菜单树查询与菜单/权限维护 |
| 认证日志 | 认证日志查询、详情查看与删除 |
| 个人中心 | 个人资料、头像与密码维护 |

## 发展方向

项目后续将围绕线程池自动发现、运行指标采集、实时状态展示、动态参数调整及异常告警等方向持续完善。
